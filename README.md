# Platter Website

Next.js website with Tailwind CSS and Swiper.js slider.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/vikasv13579/platter-nextjs-interview.git
```

2. Navigate to the project directory:

```bash
cd platter-nextjs-interview
```

3. Install dependencies:

```bash
npm install
```

4. Run the development server:

```bash
npm run dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Pages

- Homepage (with slider)
- About
- Services
- Contact (with form)

## Tech Stack

- Next.js 16
- Tailwind CSS
- Swiper.js
- Motion
